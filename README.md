# Terminal Snapshot

A terminal-style quick-notes app that runs in your browser. Each entry captures:

| Field | Filled by |
|---|---|
| Timestamp | computer (locks the moment you start typing) |
| Coordinates | computer (browser location, with accuracy) |
| Snapshot of Surroundings | you |
| Photo (optional) | you (attach, paste, or drag in) |
| Thinking about? | you |

Every save produces a portable **`.md` file**. The photo is embedded inside it by default, so one file holds the whole entry.

**Fastest path:** open page → type surroundings → `Enter` → type thought → `Enter`. Done, file saved.

- Live app (once GitHub Pages is on): `https://ryelikebread.github.io/Terminal-Snapshot/`
- Full guide: [docs/USER_GUIDE.md](docs/USER_GUIDE.md)

No build step, no dependencies, no server, no tracking. Your notes never leave your device except as files you save.
